services.bootup

CLI to restart or kill this repository's verified service process trees.

Startup stops Open WebUI, the RAG API, and Ollama before launching fresh instances. Unverified listeners and the bootup process itself are protected.

WEBUI_LAUNCH_MARKER = 'from open_webui import app; app()'
API_APP = 'Interface.server:app'
VERIFIED_API_APPS = {'vectorizer.server:app', 'Interface.server:app'}
PROCESS_IDENTITY_FIELDS = ('ExecutablePath', 'CommandLine', 'ParentProcessId', 'CreationDate')

def verified_webui_roots(config: dict, root: pathlib.Path, processes: list[dict]) -> list[int]:

Return verified top-level WebUI process-tree roots without stopping them.

Matches the configured Python executable and WebUI launch marker, includes descendants, and checks every configured-port listener belongs to those trees. Missing Python or an unverified listener raises BootError. processes is a caller-supplied Windows snapshot; ownership is rechecked later before termination.

def stop_service_roots(pids: list[int], description: str, port: int) -> None:

Stop preverified process trees, then wait for their listener port to clear.

Calls the forceful tree-termination helper for each PID and polls up to 30 seconds when targets exist. pids must already pass ownership and protection checks. Does not restart the service or remove persisted data.

def force_restart_ollama(config: dict, root: pathlib.Path, processes: list[dict]) -> None:

Verify and stop existing Ollama trees as the shutdown half of a restart.

Despite the compatibility name, this function does not launch a replacement; the caller must invoke start_ollama separately. Interrupts Ollama clients.

def force_restart_webui(config: dict, root: pathlib.Path, processes: list[dict]) -> None:

Verify and stop existing WebUI trees before a separately managed relaunch.

Does not launch WebUI itself or reset its database; active chats can be interrupted. Ownership failures abort without killing unverified listeners.

def ensure_unprotected( tree: services.windows_processes.ProcessTree, pids: list[int], protected: set[int], description: str) -> None:

Refuse termination when a target tree intersects protected process IDs.

Evaluates the supplied snapshot only. Raises BootError if any root or descendant would include the current CLI or a service excluded from shutdown. Performs no OS termination or fresh process inspection.

def kill_current_processes( config: dict, root: pathlib.Path, service: str = 'all', *, dry_run: bool = False) -> None:

Verify selected services, then stop WebUI/API/Ollama in dependency order.

Arguments:
  • config: Bootup mapping with executable paths, ports, and service identities.
  • root: Project root for relative configured paths.
  • service: all, ollama, webui, or api.
  • dry_run: Print verified targets without terminating anything.

Protects the CLI and unselected listeners, checks fresh process identity before termination, and aborts on PID reuse/ownership changes. Real shutdown force-stops process trees and interrupts active clients; databases, indexes, environments, and logs are preserved. BootError reports unsafe ownership or failed shutdown; invalid selectors raise ValueError.

def verify_api_configuration( api_url: str, headers: dict, models: common.model_config.ModelSettings, ollama_url: str) -> None:

Compare the new API's authenticated runtime settings with expected startup values.

Requests /v1/config using caller-supplied authorization headers and checks model names, allocation, retention, and Ollama URL. Raises BootError if the request fails or fields differ. Never logs the supplied API key.

def start_ollama(config: dict, settings: services.service_config.StartupSettings) -> None:

Launch configured local Ollama, verify installed models, and warm inference.

Applies context/retention and two-model residency settings to the child, appends output to ollama.log, and polls readiness. Missing required model tags raise BootError; nothing is downloaded. warm_models exercises both models and checks joint residency before startup can continue. Assumes preflight has dealt with existing processes/port ownership.

def start_rag_api( config: dict, settings: services.service_config.StartupSettings, api_key: str) -> None:

Prepare the selected embedding index, launch Uvicorn, and verify API readiness.

Passes authoritative model/source settings and the secret through a child environment, not argv. Index preparation runs before the HTTP readiness timeout and can build/write vectors and BM25. Preparation errors prevent API launch. Then starts Interface.server:app on the configured loopback endpoint, logs to rag-api.log, and verifies model/runtime configuration with bearer-authenticated requests. Already launched services are not rolled back on a later failure.

def start_webui( config: dict, settings: services.service_config.StartupSettings, api_key: str) -> None:

Launch WebUI in its separate environment and wait for its local HTTP page.

Supplies the GeorgeGPT OpenAI connection and key through the child environment, retains WebUI's persistent signing-key behavior, and disables client-side execution integrations. Creates the runtime working directory and appends diagnostics to open-webui.log. Does not create an account, reset storage, save a connection directly, or open the browser. Missing interpreter or readiness failures abort startup.

def start_services(config: dict, root: pathlib.Path) -> None:

Restart the complete local stack using validated settings and its saved key.

Resolves configuration, reads WebUI's saved connection secret, verifies/stops existing trees, then starts Ollama, API, and WebUI in dependency order. Interrupts active chats and other clients of this Ollama instance. Returns only after readiness checks succeed. Does not pull missing models; partial startup is not rolled back if a subsequent stage fails.

def argument_parser() -> argparse.ArgumentParser:

Return the start/stop CLI parser without reading configuration or running services.

Defines command aliases, custom config, selective stop, and stop dry-run flags. Cross-option validation is performed by main after parsing.

def main() -> int:

Run managed start/restart or verified shutdown from command-line arguments.

Loads the selected bootup JSON, rejects stop-only options on start, and dispatches start_services or kill_current_processes. Returns 0 on success, 1 for handled operational failures; argparse reports invalid input separately. Windowless launches route status/errors to logs. No automatic rollback occurs.
