# Agent instructions

- This is a repository RAG chatbot. Python modules live in `vectorizer/`: `vectorize.py` indexes safe UTF-8/text files using structural chunks, Chroma vectors and a local SQLite FTS5/BM25 corpus; `retrieval.py` combines searches; `chat.py` answers through Ollama; `server.py` provides an authenticated OpenAI-compatible API for Open WebUI. The chatbot has no tools, filesystem access, Proxmox access, or command execution. Open WebUI Knowledge/RAG is not used.
- Install dependencies with `python -m pip install -r requirements.txt`.
- Ollama serves chat and embeddings. Defaults are `qwen3-embedding:0.6b` and `qwen2.5-coder:7b`; override with `OLLAMA_EMBEDDING_MODEL` / `OLLAMA_CHAT_MODEL` if required. Set `OLLAMA_BASE_URL` if needed. From the project root, index with `python -m vectorizer.vectorize PATH_TO_REPOSITORY`; query with `python -m vectorizer.ask 'QUESTION'`. For Open WebUI set `RAG_API_KEY`, then run `python -m uvicorn vectorizer.server:app --host 127.0.0.1 --port 8001`; configure OpenAI-compatible URL `/v1` and model `GeorgeGPT`. Manual bootup is `pythonw -m vectorizer.bootup`, configured in `config/bootup.json`.
- On Windows, create the environment with `py -3.12 -m venv .venv` and use `.\.venv\Scripts\python.exe` for installation and commands; activation is optional (`.\.venv\Scripts\Activate.ps1` in PowerShell).
- Verify syntax with `python -m compileall -q vectorizer tests`; run tests with `python -m unittest discover -s tests -p "test_*.py" -v`. `python -m vectorizer.verify_index PATH_TO_REPOSITORY` is the explicit chunking/vector/BM25 audit; do not add full metadata scans to runtime startup. The embedding integration test needs Ollama with the embedding model pulled. Live usage needs the index plus Ollama chat/embedding models.
- Chroma and the BM25 SQLite index persist under `chroma_db` at the project root, independent of working directory; explicit relative `--db-path` values are relative to current directory. Preserve existing databases, environments and runtime logs. Keep collection, DB path, and embedding model consistent for indexing/querying. Indexing excludes actual `.env` files, common key/credential files, binary/large files, caches, environments, and generated directories; review filters before indexing other repositories.
